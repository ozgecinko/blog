# Blog Posts

This repository stores Markdown versions of my blog posts.

## Structure

All posts live in the `posts/` directory.

Post filenames follow this pattern:

```text
posts/YYYY-MM-DD-post-title.md
```

## Post Format

Each post is a Markdown file with frontmatter metadata at the top:

```markdown
---
title: "Post Title"
date: "2026-07-20"
description: "A short summary for previews."
tags:
  - python
  - audio
image: "https://example.com/cover.png"
source: "https://example.com/original-post"
---

Post content starts here.
```
